# ТатварЗөвлөх

Татварын хуулийн зөвлөгөө, мэдээлэл, гүнзгийрүүлсэн гарын авлага файл худалдаалах, татварын эрсдэл тооцоолох вэб сайт.

## Бүтэц

- `index.html` — нүүр хуудас (бүх хэсэг нэг хуудсанд)
- `assets/data.js` — нийтлэл, гарын авлага (үнэ), эрсдэлийн асуулт, банкны данс. **Агуулгыг энд засна.**
- `assets/app.js` — шүүлтүүр, сагс, захиалга, зөвлөгөөний маягт
- `assets/bot.js` — татварын эрсдэлийн бот: асуулт-хариулт (1-р шат) ба санхүүгийн үзүүлэлтийн шинжилгээ (2-р шат)
- `assets/styles.css` — загвар (утас, гэрэл/харанхуй горимд тохирсон)

## Ажиллуулах

Ямар нэг суулгалт шаардлагагүй. `index.html`-ийг браузерт нээх эсвэл:

```
python3 -m http.server 8000
```

## Дараагийн алхам

- `assets/data.js` доторх банкны данс, утас, и-мэйлийг бодит мэдээллээр солих
- Захиалга, зөвлөгөөний хүсэлт одоогоор зөвхөн хэрэглэгчийн браузерт хадгалагдана — сервер эсвэл QPay холбох
- `data.js` дахь `BOT.industries` салбарын жишиг ашгийн хувь, `BOT.minWage` хөдөлмөрийн хөлсний доод хэмжээг бодит тоогоор шинэчлэх
- Нийтлэлийн тоо, хувь хэмжээг хуулийн хамгийн сүүлийн хувилбартай тулгах
